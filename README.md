# vsav-p2-replay-takeover
most of the code comes from fightcade itself https://www.fightcade.com, and the N-bee training mode https://github.com/NBeing/VSAV_Training. small changes to allow you to use replay takeover as p2. use alt + 6 instead of alt + 5 to start a recording as player 2. replace fbneo-training-mode.lua in the fbneo training mode folder, and the missions.lua in the addon folder.
